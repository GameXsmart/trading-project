Horizon sweep - raw output
==========================

Produced by re-running the Phase 6 walk-forward gate across 3 timeframes and 5-6
horizons each, on BTC/ETH/SOL, with every configuration capped at the same number of
evaluation points so the significance test does comparable work in each row.

Columns: asset, timeframe, +horizon (bars), forecast reach in hours, evaluation points
used / available, median move threshold, up/flat/down class balance, best-scoring model
overall, its Brier skill against climatology, its paired one-sided p-value, and which
models passed the full gate (skill floor + significance surviving Benjamini-Hochberg
across all 2,032 slices).

Note that `sentiment`, `orderflow` and `sequence` abstain on 100% of points on this
data, so wherever one of them is "best" the winning entry is a uniform distribution.

Committed as evidence. See docs/PHASES.md, Phase 6, for the analysis.
