Crypto Market Intelligence Engine · Operator's handbook

Everything this thing does, in plain English

It watches crypto markets, looks for patterns, and tells you what it finds — including, almost always, that it has found nothing worth acting on. That is the system working correctly, not a fault. This page explains how to run it, what every part does, and how to read what it says.

01 What it is

And, just as importantly, what it isn't.

This is an analysis tool. It collects price data from crypto exchanges, computes indicators, hunts for repeatable patterns, reads news, runs eight independent prediction models, and then applies a strict evidence test before it will tell you anything at all.

Most of the time it fails that test and says insufficient evidence. That is the headline finding of the whole project, and the interface is built to state it plainly rather than dress it up.

It does not trade

There is no order-execution code anywhere in it, no exchange trading keys, and no path from a prediction to a venue. It only reads public market data. Two automated tests check this on every run: no web route accepts a data-changing request, and no route path contains words like order, buy, sell or withdraw. It is also not financial advice.

02 Starting it

One file. Everything else is automatic.

Open the project folder and double-click run-engine.bat.

On a first run it will set itself up: create the Python environment, install what it needs, build the database, and download about a year of price history. That takes a few minutes and happens once. After that it starts in seconds.

To stop everything, double-click stop-engine.bat. Your stored data is untouched — restarting picks up exactly where it left off.

If you'd rather use the command line

> mie run

That runs just the data collector. The launcher does this plus two other things, which is why double-clicking is easier.

Leave it running

The engine gets more useful the longer it runs, because it is short of data, not short of code. News feeds only carry about a week of history, and funding-rate data only accumulates from the moment collection starts. Weeks of uptime is what turns "untested" into "tested".

03 The three windows

The launcher opens three. Each does a different job. Leave them open.

MIE ingest

Collects price bars, funding rates and open interest as they happen, and scores how trustworthy each feed is. The most important one to leave running.

MIE dashboard

Serves the web page at 127.0.0.1:8000. Read-only — it can show you things and change nothing.

MIE cycle

Once an hour: writes down a prediction, checks older predictions that have come due, and reports whether it learned anything.

Closing any window stops just that piece. The other two carry on.

First load is slow

The dashboard takes 30–60 seconds to answer the first time. It re-checks the accuracy of every prediction ever stored before it serves a page. After that it is quick.

05 How it works

Twelve stages. Data goes in at the top and either earns its way to the bottom or gets stopped — usually stopped.

  1. Collecting the data

    Pulls price bars from Binance, with Coinbase and Kraken as backups. If one exchange fails, the next serves the request and the switch is recorded — because "the data arrived, but from the third-choice venue" is worth knowing.

  2. Checking the data

    Ten checks per bar: impossible values, gaps, duplicates, wrong timestamps, frozen prices, extreme moves, disagreement between exchanges. Impossible bars are rejected. Suspicious-but-possible bars are kept and flagged — deleting them would invent a calmer market than the real one.

    Every feed gets a trust score from 0 to 1 that reduces confidence downstream.

  3. Computing indicators

    Sixteen standard indicators — moving averages, RSI, MACD, ATR and so on — plus support and resistance levels, updated one bar at a time.

  4. Reading market state

    Works out the trend on each timeframe and whether they agree. A daily uptrend with an hourly downtrend is a pullback; both pointing down is something else.

  5. Testing patterns

    Eleven classic chart patterns, each measured against what happens on an average bar. A pattern only gets used if it beats that baseline by a statistically significant margin.

    Result: 9 of 342 combinations passed, and every survivor predicts movement, not direction.

  6. Reading news

    Pulls crypto news, groups duplicate coverage of the same story, and classifies it by topic and tone.

    Whether news moves price is not yet measurable — needs 25 events per category, currently has 6.

  7. Eight models predict

    Each reads different data — indicators, price dynamics, historical lookalikes, regime, news, other coins, derivatives, pattern sequences — and outputs a probability for up, flat and down. Any of them can decline to answer.

  8. Deciding whether to publish

    Models only get influence by proving skill. Six of eight must agree, the system must have a calibration record for the current conditions, and confidence must clear a floor. Disagreement blocks publication rather than averaging into a confident middle.

    Currently nothing is published, on any asset, at any time.

  9. Testing it honestly

    Splits history into chunks, learns on early ones, tests on later ones, and deletes the bars near the boundary that would leak the answer across. It also actively probes each model by feeding it corrupted future data — a model whose answer changes was cheating.

  10. Learning from outcomes

    Predictions are written down before the outcome exists and can never be edited. When the time is up, the system scores them and reports what changed.

    So far: 0 weight changes, 6 calibration corrections from 8,100 resolved predictions.

  11. Showing it

    The dashboard cannot display a direction without also displaying its confidence and the conditions that would prove it wrong. That rule lives in the data format, so no screen can break it.

  12. Alerting, sparingly

    Rules watch for volume spikes, regime changes, correlation breakdowns and feed problems — inside a strict budget, because an alert system nobody reads is worse than none.

    Over 29 days: 1,238 raised, 422 delivered. The rest is summarised, never silently dropped.

07 What to do, and when

Mostly: leave it alone. Here is the useful rhythm.

WhenDo thisWhy
Every day Nothing. Glance at the dashboard if you like. The cycle window handles predictions and scoring on its own.
Weekly mie status and mie quality Confirms data is still arriving and no feed has quietly gone stale.
Every few weeks mie evaluate BTC The real question: has any model started beating the baseline?
Monthly mie news-impact BTC Once enough news has accumulated, this becomes answerable.
After a restart Double-click run-engine.bat It resumes. Duplicate predictions are ignored, so nothing gets double-counted.
The one thing worth doing

Come back in a week and run mie evaluate BTC. Two models — the ones reading derivatives and news — had no data to work with until recently. That week of collection is what makes them testable for the first time.

08 What the results mean

The central finding, and how to read the numbers behind it.

The system compares every model against climatology — a deliberately stupid forecaster that ignores current conditions entirely and just says "here is how often prices went up, flat and down historically". Beating that is the minimum bar for claiming you know anything about now.

The one number to understand

Models are scored with a Brier score. Lower is better. The key reference point is 0.6667 — that is the score you get by refusing to answer and saying "up, flat and down are all equally likely".

ForecasterBrierReading
sentiment, orderflow, sequence0.6667These decline to answer. Tied for best.
baseline_climatology0.6668The "how often historically" forecaster.
similarity0.6692Worse than saying nothing.
regime, technical, crossasset, timeseries0.676–0.686Worse still.
The finding

Saying nothing beats history, and history beats every opinion any model formed. Over 8,100 scored predictions, not one model earned influence. That held up when tested across 48 different forecast lengths — from 3 hours to 60 days — covering 2,032 separate tests.

Why this is believable rather than just discouraging

A tool that always says "no signal" could simply be broken. So the detectors are tested in both directions: a deliberately cheating model that can see the future is caught and flagged; a fake model with genuine skill is correctly certified; a deliberately miscalibrated forecaster is corrected. The instruments work. They are pointed at something that does not appear to be there.

One honest caveat

Until very recently, two of the eight models had no data at all — the derivatives feed was empty and news covered only five days out of a year. Their silence was a missing input, not a verdict. That is now fixed, but it means the finding is solid for price-based models and still untested for those two.

09 Alerts

What it will interrupt you for, and the budget that stops it nagging.

By default alerts go to the console and a local file. Discord and Telegram work if you set them up, but nothing is sent anywhere without you deliberately configuring it.

AlertMeaningPriority
Data qualityA feed is degrading. Everything else is now suspect.Critical
Prediction invalidatedA published call has been proven wrong and no longer stands.Critical
Regime changeMarket conditions shifted, so prior measurements may not carry over.Important
Correlation breakdownCoins that normally move together have stopped.Important
Volume anomalyUnusual volume. Expect bigger moves — direction unknown.Notable
Volatility expansionThe market has got choppier than usual.Notable
Major newsA story with unusually broad coverage.Notable

The budget is 6 an hour, 30 a day, with a small reserve only critical alerts can use. Repeats of the same thing are suppressed, and roughly two thirds of what the rules raise never reaches you — but you get a periodic summary saying how many were held back, so silence never means "nothing happened" when it actually means "budgeted".

11 Limits and safety

What it can't do, and what it will never do.

What it cannot tell you

It cannot tell you what price will do. That is not modesty — it is the measured result across five independent tests. What it can do is detect when movement is likely to be larger than usual, notice when conditions change, tell you when its own data is unreliable, and stop you fooling yourself with a result that is really noise.

Where it might yet find something

Shorter timeframes and order-book data were never tested. Ranking coins against each other rather than predicting each in isolation is a different question that was never asked. And the one thing that did survive testing — volume spikes and quiet periods preceding bigger moves — says nothing about direction but is real.

Never

It will never place a trade, move money, hold exchange keys, or connect a prediction to a venue. Every output is a probability with uncertainty attached, never a guarantee, and none of it is financial advice. If you act on anything here, that is your decision and your risk.
